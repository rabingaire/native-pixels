Optional source downloads#

The lessons create a project named native-pixels-game from an empty directory. Every required application file and test file is printed in the relevant chapter, and the book includes its PNG artwork. You can complete the game without opening an online source repository.

For convenience, the Native Pixels repository also contains the completed project and a snapshot for each chapter. A checkpoint is the full source at the end of that chapter, before optional experiments and challenges. These copies are useful for comparison or for revisiting a lesson; they are not additional required instructions.

Find the matching version#

Location in the optional downloadContents
checkpoints/01 through checkpoints/23Complete application snapshots for their numbered chapters. Keep each directory’s source, shader, and assets together.
projectThe final animated room from chapter 23.
testsAuthor-maintained tests. The learner test files are also printed directly in chapters 21 and 23 with imports for the reader’s directory layout.
authoring and toolsWebsite generation and author verification tools; not needed to follow the lessons.

When building an optional snapshot, use that snapshot’s src directory in place of src in the platform build command. The native libraries still need to be installed. The complete final source is also available in the final-source appendix. The dated native execution results and external API references are collected in Sources and verification.
